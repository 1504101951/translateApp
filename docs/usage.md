# 使用说明

安装位置固定为 `/Applications/TranslateApp.app`。菜单栏翻译图标提供设置、区域截图、翻译历史、仅使用快捷键开关和退出入口。

## 选区翻译

1. 在其他应用拖选、双击、三击，或用 ⌘A、Shift 配合方向/Home/End/Page 键选中文字，旁边出现「翻译」按钮。键盘选区暂时读不到文字时先显示待确认按钮，点击后才读取。文件和安全控件不显示按钮。
2. 点击按钮展开双栏卡片：左译文、右原文，按段落同行对齐，悬停译文高亮对应原文，两栏可分别复制全文。按钮和卡片顶部标题区可拖动。两栏标题旁的朗读按钮用系统离线语音朗读该栏全文，再次点击停止；关闭卡片或开始新翻译时自动停止。标题区的模式菜单可切换为「润色」「纠错」「解释」，对同一原文重新处理：润色与纠错保持原文语言，解释使用主要语言；这三种模式需要把默认翻译服务设为模型服务（OpenAI、DeepSeek 或 Anthropic），结果不写入翻译历史。
3. 全局快捷键 **⌃⌥T** 直接翻译当前选区。开启「仅使用快捷键」后不再自动显示按钮。
4. 输入翻译快捷键 **⌃⌥R** 翻译输入框中选中的文字，没有选中文字时翻译整个输入框；完成后直接替换为译文并关闭卡片，可用来源应用的 ⌘Z 撤销。来源应用已切换或处于密码输入时不替换，卡片保留译文。替换经剪贴板完成，0.5 秒后还原原剪贴板。
5. 自动检测只读辅助功能；点击翻译或用快捷键时允许一次性复制读取，保留网页段落与换行，并恢复剪贴板。读取为空时显示失败卡片，不发送旧选区。
6. 语言在设备上识别：设置次要语言时，主要语言译为次要语言，其余译为主要语言；未设置时统一译为主要语言，已是主要语言的文本直接展示、不发请求。单次上限 50,000 字符。
7. 小按钮随选区清空、外部点击、切换应用或新选区消失；展开后的卡片只通过 Esc 或 × 关闭。快捷键翻译会替换为新内容。

## 词典与生词本

1. 选中 1–3 个英文单词（不超过 40 个字符）或 1–4 个汉字翻译时，同时用 macOS「词典」App 已启用的词典离线查询；查到时卡片右栏显示「词典」释义，左栏仍为译文，右栏朗读按钮读出原词。
2. 卡片标题区的「加入生词本」把单词、译文与释义保存到本地；同一单词再次加入会更新内容。
3. 菜单栏「翻译历史」窗口顶部可切换「生词本」：按加入时间倒序查看、删除，底部「导出 CSV」经保存面板导出（UTF-8、无表头，列为单词、译文、释义），可直接导入 Anki。

## 术语表

1. 「设置 → 翻译」的「术语表」行点击「管理术语」，在弹窗中「添加术语」填写原文术语、译法与目标语言（默认主要语言），也可编辑或删除已有术语；译法留空表示保留原文不译。同一目标语言下同一术语（不区分大小写）只能有一条，改动自动保存。
2. 术语表只对模型服务（OpenAI、DeepSeek、Anthropic）的翻译生效，覆盖选区、输入、截图与实时翻译；谷歌、百度与 Apple 系统翻译的接口不支持按请求传入术语，润色、纠错、解释也不使用术语表。
3. 每次翻译只把原文中出现、且目标语言一致的术语发给模型；英文等术语按整词匹配，`API` 不会命中 `capital`。

## 截图

1. 菜单栏「区域截图…」或 **⌃⌥S** 冻结当前画面后框选，Esc 取消。首次使用按提示授予屏幕录制权限，系统要求时重开 App。
2. 工具栏优先放在选区下方，其次上方、右侧、左侧；空白不足时放进选区内侧。拖动选区时工具栏隐藏。
3. 非文字输入状态按回车或双击执行「设置 → 截图 → 确认截图 → 回车或双击确认时」的动作并退出：复制图片（默认）、复制并保存或上传并复制链接；失败时保留编辑。
4. 保存写入「截图目录/截图/YYYY-MM-DD」，默认根目录为 `~/Pictures/截图`；文件名含日期、时间和毫秒，重名追加序号。「复制并保存」先保存再复制，保存失败不改剪贴板。操作结果提示显示 1 秒。
5. 截图只有在点击「上传」或确认动作为上传、并在提示目标的弹窗中点「上传」后才会上传；只有点击「识别文字」「翻译文字」才识别或发送文字。
6. 菜单栏还提供：「截取上次区域」冻结上次复制、保存或贴图时的显示器并选中同一区域，显示器断开或分辨率变化时提示失效；「截取显示器」冻结所选显示器并选中整屏；「延时截图」3、5、10 秒后截取指针所在显示器，倒计时显示在菜单栏图标上，期间可正常操作其他应用，可在菜单中「取消延时截图」，倒计时期间再发起截图会立即截图。
7. 「设置 → 截图 → 截图包含鼠标指针」默认关闭；打开后冻结画面包含鼠标指针，MCP 截图不受影响。

### 框选精确控制

- 「截图」或「光标」工具下，选区左上角外侧显示像素尺寸「宽 × 高」，选区贴近顶部时显示在选区内。
- 没有文字输入且没有选中标注时：方向键移动选区 1 像素，⇧ 为 10 像素；⌥+方向键以左上角为锚点调整宽高（→/↓ 增大，←/↑ 减小），⌥⇧ 为 10 像素。选区不越出截图，最小边长 8 像素。
- 工具栏「比例」展开比例行：自由、1:1、4:3、3:4、16:9、9:16。选择后选区以左上角为锚点保持宽度调整高度，超出截图则整体缩小；之后新框选、拖动控制点与 ⌥+方向键都保持比例。每次截图默认「自由」。

### 标注

- 图形：矩形框、圆形框、矩形填充、圆形填充；另有箭头、画笔、马赛克画笔（12 像素网格）与荧光笔。线宽 1–20pt，默认 3pt。每种工具分别记住自己的颜色、粗细与模式，重启后保留。
- 荧光笔：画笔第二行选择「荧光笔」，默认黄色、16pt，以 40% 不透明度覆盖，下方文字仍清晰；同一笔来回涂抹不加深。
- 编号：选择「编号」后单击放置 1、2、3… 的圆形标记，按住拖动可调整位置后松开；可连续快速单击。编号按放置顺序排列，撤销或重做后自动重新编号；颜色可调，数字按底色自动取黑或白。
- 光标工具选中已有标注后可修改样式。画笔使用与粗细、颜色一致的圆点光标。
- 文字：点击放置文字框，回车换行；点击框外、Esc 或切换工具结束输入；空文字框自动删除；单击选中、再次点击进入编辑；拖动只改宽度，高度随内容。
- ⌘Z 撤销，⇧⌘Z 重做。

### 美化

- 工具栏「美化」展开美化行：背景（无或 6 种渐变）、内边距小/中/大（32/64/96pt）、直角或圆角（12pt）、阴影开关。选择背景后，选区四周直接显示导出效果。
- 复制、保存与回车复制输出美化后的图片；贴图、识别文字与翻译文字使用原图。每次截图默认不美化，选「无背景」即关闭。

### 取色与标尺

- 「截图」的子级行有「取色」与「标尺」。取色：指针处显示色块与 `#RRGGBB`（截图源像素），单击复制该色值。标尺：拖动画出测量线，终点旁显示「长度 px（Δx × Δy）」，单位为截图像素。
- 测量线与取色标签不出现在复制、保存、贴图或上传的图片中，也不进入撤销；新拖动替换上一条，切换工具或新截图后清除。

### 上传分享

- 「设置 → 截图 → 上传分享」点「编辑…」填写 S3 兼容存储（AWS S3、Cloudflare R2、MinIO、阿里云 OSS、腾讯云 COS 等）：服务地址（https）、区域、存储桶、可选路径前缀与分享链接前缀，以及 Access Key ID、Secret Access Key。密钥保存在 macOS 钥匙串，再次编辑时留空保留。
- 工具栏「上传」先提示「将上传到 主机/存储桶」，点「上传」后上传与复制相同的导出图（含美化），成功后复制分享链接。文件名为「路径前缀/日期-时间-随机串.png」；未填分享链接前缀时链接为 `服务地址/存储桶/文件名`，存储桶需允许公开读取才可直接打开。
- 未配置上传目标时只提示去设置，不发送任何图像。

### 识别、翻译与贴图

- 「识别文字」：在本机同时识别文字与二维码/条码，打开「识别结果」弹窗，按 Markdown 渲染标题、段落、列表与表格（宽表格可横向滚动），可选中部分复制；「复制全部」复制 Markdown 原文，弹窗不自动关闭。
- 识别到二维码或条码时，正文顶部逐条列出类型与完整内容，「复制内容」复制该条；内容是 http/https 链接时可点「打开链接」用默认浏览器打开并关闭截图，其他内容只能复制。既无文字也无码时提示「画面中没有可识别的文字、二维码或条码」。
- 「翻译文字」：识别后用当前翻译服务翻译，译文盖在截图原位，结果写入翻译历史。
- 「贴图」：把截图钉在屏幕最上层，不抢当前应用焦点；单击拖动，滚轮或捏合缩放，双击或 Esc 关闭。

### 截图历史

- 菜单栏「翻译历史」窗口顶部切换到「截图历史」，开启「记录截图历史」（默认关闭）后，复制、保存或贴图成功的截图另存一份到 App 自己的历史目录；同一次截图多次导出只保留最后一次的图片。
- 最多保留 100 张、30 天内的截图，超出时删除最早的记录及其图片；保存到截图目录的文件不受影响。
- 每条显示缩略图、截图时间与像素尺寸，可打开、复制图片、在 Finder 中显示或删除；图片被移走时显示「图片文件已缺失」，只能删除。「清空截图历史」删除全部记录与历史图片。
- 勾选卡片左侧的方框后可处理多张截图：「拼接」（至少 2 张，纵向或横向，按截图时间先后排列，不缩放，尺寸不同时居中、空白透明）；「拆分」（1 张，按高度等分为 2–10 段，余数并入最后一段）；「比较」（2 张，并排显示，可高亮像素差异并显示差异像素占比）。拼接与拆分的结果作为新记录加入截图历史，不受「记录截图历史」开关限制。

## 录屏、GIF/APNG/WebM 与滚动长截图

1. 工具栏「截图」下的「录制」可选区域、窗口、全屏目标；窗口目标按应用列出，截图前的当前应用优先。视频为 30fps、无音轨 MP4。
2. 「滚动长截图」框选后立即开始，默认手动向下滚动来源应用；相邻画面需有足够重叠，顶部与底部固定区域自动去重，无法可靠拼接时停止并保留已确认部分。
   - 「设置 → 截图 → 长截图 → 滚动方式」选「自动滚动」后，App 自动向下滚动选区里的内容，不移动指针；到底自动暂停并提示「已到底部，已暂停」，点「结束」完成，点「继续」恢复自动滚动。
   - 自动滚动中在选区内滚动滚轮或触控板即改为手动（提示「已切换为手动滚动」）；在选区外滚动或移动鼠标不受影响。暂停按钮暂停，「继续」恢复自动滚动。
   - 自动滚动需要辅助功能权限，并要求来源窗口提供可调整的滚动条（Safari 网页可以；ChatGPT、微信等部分应用不行），不满足时提示并改为手动滚动。
3. 采集期间使用悬浮条：暂停／继续、结束、放弃。暂停时间不计入视频；放弃立即清理临时文件。
4. 视频结果窗口可播放、裁剪、保存 MP4、导出 GIF、导出 APNG、导出 WebM；长图结果窗口可滚动查看、保存、复制或放弃。GIF 与 APNG 共用「设置 → 截图」中的帧率（1–30fps，默认 10）与最大宽度（默认不限），只缩小不放大，循环播放。WebM 为 VP8 编码、无音轨，保持原分辨率与原帧时间，不使用 GIF 设置，可在浏览器中播放；由系统 WebKit 编码，本机不支持 VP8 编码或编码器丢帧时提示失败且不保存。
5. 「裁剪」让播放器显示系统裁剪条：拖动首尾手柄后点「裁剪」确认，点「取消」保持原来的区间，可再次进入调整。确认后播放、保存 MP4、导出 GIF、APNG 与 WebM 都只使用所选区间；裁剪后保存 MP4 会重新编码，转换中可取消。源录制不改写，关闭结果窗口后裁剪不保留。
6. 「设置 → 截图 → 录制时显示鼠标点击」默认关闭；打开后区域与全屏录制在点击处显示系统点击高亮。窗口（应用）录制不含鼠标指针，不显示点击。
7. 保存位置：MP4 到「截图目录/视频/日期」，GIF 到「截图目录/gif/日期」，APNG 到「截图目录/apng/日期」（扩展名为 .png），WebM 到「截图目录/webm/日期」，长图到「截图目录/截图/日期」。

## 实时翻译

1. 截图工具栏的「实时翻译」选择区域、窗口或全屏目标后开始；译文按段落盖在原文位置，画面变化时持续更新。
2. 已翻译过的段落直接复用，不重复请求；网络波动自动重试，密钥错误或额度不足立即停止并提示。
3. 悬浮条可暂停、结束、放弃。
4. 开启「设置 → 截图 → 实时翻译时同时录制」后同步录制，画面包含译文，结束后进入录制结果窗口，可导出 GIF。

## 截图工具栏

「设置 → 截图 → 截图工具栏」可排序、显示或隐藏工具，并录制只在截图编辑中生效的快捷键；隐藏的工具仍可用快捷键调用。

拖到某行左半边调整顺序，拖到右半边挂为该工具的子级，最多两级；只有点击后停留的工具（如图形、文字）能作为父级。默认「截图」下挂「录制」与「滚动长截图」。键盘上下键移动，右键挂到上方工具下，左键移回一级。

## 翻译历史

1. 菜单栏「翻译历史」打开独立窗口。卡片显示来源应用（或「截图」）、完成日期、完整译文与原文，可选中复制。每批 10 条，滚动加载，「刷新历史」回到最新。
2. 完整成功的选区翻译与截图文字翻译各自记录；失败、取消或未完成的不记录。
3. 「记录历史」默认开启，关闭后只停止新记录。记录不含选区坐标、截图图片或凭据。

## 设置

1. 外观：浅色、深色、跟随系统；玻璃透明度 0%–80%（默认 20%）。系统开启减少透明度或增强对比度时使用不透明材料。
2. 语言、仅使用快捷键、全局快捷键、翻译服务、排除应用、登录启动和权限状态。排除应用同时禁止自动捕获与快捷键捕获。
3. 快捷键点击后录制实际按键，Esc 或失焦取消；与系统或其他应用独占的组合冲突时保留原组合。macOS 无法枚举其他应用的内部快捷键。
4. 修改自动保存；失败时保留草稿并提示重试。

## 翻译服务

在「设置 → 翻译服务 → 添加服务」填写配置，「测试连接」只发送 `Hello world.`（Apple 系统翻译只检查语言包），「确定」保存，再选择默认服务。支持多个命名配置；翻译失败不会自动换用其他服务。

| 服务 | 必填项 | 默认 API Base URL |
|---|---|---|
| Google 免费接口（非官方，初始默认） | 无 | 内置消费端接口 |
| 百度通用翻译 | App ID、密钥 | `https://fanyi-api.baidu.com` |
| 谷歌翻译（Cloud Translation Basic v2） | 已启用 Translation API 的项目 API Key | `https://translation.googleapis.com` |
| OpenAI | API Key、模型 ID | `https://api.openai.com/v1` |
| DeepSeek | API Key、模型 ID，固定关闭思考 | `https://api.deepseek.com` |
| Anthropic 原生 Messages | API Key、模型 ID | `https://api.anthropic.com/v1` |
| Apple 系统翻译 | 无 | 无，本机离线翻译 |

1. Base URL 不含接口路径或密钥；远程服务需要 HTTPS，本机 `localhost`、`127.0.0.1`、`::1` 可用 HTTP。可用性取决于服务商账户、网络和额度；消费端会员不等于 API 凭据。
2. API Key 与百度 App ID 只存在 Keychain。编辑时不显示已存密钥，留空即保留；删除服务会删除凭据。只有翻译、测试连接和修改凭据时才访问钥匙串。OpenAI、DeepSeek、Anthropic 等模型服务的 API Key 可留空（如不校验密钥的本机服务），留空时请求不带认证头；谷歌翻译与百度翻译仍须填写。
3. Apple 系统翻译使用 macOS 本机翻译模型，不联网、不保存凭据。语言包需先在「系统设置 → 通用 → 语言与地区 → 翻译语言」下载；缺少时失败卡片写明缺少的语言对，「测试连接」列出主要语言与次要语言双向的安装状态。原文语言无法识别或语言对不受支持（如简体与繁体中文互译）时直接提示。
4. 模型配置可编辑独立提示词。开启「按段落双语对照」后，模型按编号返回每段译文，编号缺失、乱序或为空都报失败。
5. 长文按约 4,000 字分片；失败卡片保留已完成部分，「重试」从失败片继续，全部成功才写入历史。

接口参考：[百度通用翻译](https://fanyi-api.baidu.com/doc/21)、[Google Cloud v2](https://cloud.google.com/translate/docs/reference/rest/v2/translate)、[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages)、[Apple Translation](https://developer.apple.com/documentation/translation/translationsession)。
