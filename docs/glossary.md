# 选区翻译上下文

本文规定在其他 macOS 应用中翻译选中文字时使用的用语。

**当前平台范围**：产品只支持 macOS 26 及以上。Flutter 负责界面和翻译逻辑；AppKit 提供原生 Liquid Glass 材料与系统能力。Android、iOS、Windows 属于后续平台方向，不进入当前规格、工单或验收。

不要使用：当前跨平台发布、四平台交付

## 用语

**截图草稿**：冻结画面里持有的本地 PNG。它有采集 ID、像素尺寸和时间戳，可以复制图片、显式保存，或被另一次采集替换。关闭预览结束草稿，不撤销已导出的文件或剪贴板内容。它与选区会话、贴图分开。识别文字和翻译文字只在用户点击对应动作后发生。

**截图历史**（#29）：开启「记录截图历史」后，复制、保存或贴图成功的截图草稿在 App 历史目录中保留的一份 PNG，含截图时间与像素尺寸；同一截图草稿只保留最后一次导出。默认关闭，最多 100 张、30 天，在翻译历史窗口的「截图历史」分段查看、打开、复制、在 Finder 中显示或删除。它与保存到截图目录的文件分开，清理不触碰后者。

**上次区域**（#105）：截图编辑中最近一次复制、保存或贴图成功时的显示器与选区像素矩形，保存在本机偏好，重启后保留。「截取上次区域」冻结同一显示器并选中该矩形；显示器断开或像素尺寸变化即失效，不改截其他屏幕。

**步骤编号**（#107）：截图标注中带数字的实心圆标记。数字不随标记保存，按标记在截图草稿中的放置顺序依次为 1、2、3…；撤销或重做增删标记后，其余标记按顺序重新编号。

**确认动作**（#111）：在截图编辑中按回车或双击确认时执行的导出，取值为复制图片或复制并保存；成功后关闭截图。

**截图快捷键**：可单独配置的全局快捷键，默认 ⌃⌥S，用来开始系统区域框选。翻译快捷键和截图快捷键一起校验、一起保存；对调两者已有组合时复用系统注册。

**实时翻译会话**（#24）：用户显式开始的会话，持续识别所选屏幕区域中的文字，并把变化后的文字交给默认翻译服务。切换来源应用后会话仍在，支持暂停、恢复和结束；采集不可用时结束。跟踪对象是屏幕区域，不是应用里的文字选区，因此与选区会话分开。只有开启「实时翻译时同时录制」时才同步录制该会话；不处理音频。

**贴图**（#22）：独立、可移动的图片预览，留在其他应用之上，直到用户关闭。单击拖动，滚轮或捏合缩放，双击或 Esc 关闭。它与翻译浮层分开，来源应用失焦时不结束。

**仅使用快捷键**：设置和菜单中的开关，标签为「仅使用快捷键」。开启后关闭自动翻译触发，全局翻译快捷键仍可用。默认关闭。

**百度服务**：使用百度官方通用翻译 API 的翻译服务。App ID 和密钥保存在 macOS Keychain。

**双语对照**：同一行显示一个本地原文段落和它的译文，左译文、右原文。悬停译文时高亮对应原文。普通服务按原文段落顺序翻译。模型段落模式接收带连续编号的全部原文，并返回有序的 `{id, translation}`；编号必须恰好覆盖每一段。原文和分隔空白来自本地输入。段落按非空原文行划分；字符选区和未换行长段内部的语义切分不是对齐边界。编号校验不能证明译文语义准确。

**自动翻译触发**：选区手势之后，由用户控制是否出现翻译按钮。鼠标手势需要可读的辅助功能文字。键盘选区手势可以在来源、权限和文本上下文检查后进入待确认触发。被动检测不注入复制按键。结果保持显示时忽略自动手势。关闭自动捕获只结束尚未展开的触发。

**生词本**：从译文卡片加入的单词或短语，含译文与词典释义，保存在本地 SQLite，可在翻译历史窗口查看、删除并导出为 CSV。只有查到词典释义的单词或短语可以加入。

**术语表**（#104）：设置中维护的一组术语，每条含原文术语、译法与目标语言；译法为空表示保留原文不译。只对模型服务的翻译模式生效，每次请求只携带原文中出现且目标语言一致的术语。同一目标语言下术语不区分大小写唯一。

**卡片模式**：译文卡片标题区菜单中的翻译、润色、纠错、解释。非翻译模式由默认模型服务按内置提示词处理同一原文，结果不属于翻译历史。

**输入翻译快捷键**：可配置的 macOS 快捷键，默认 ⌃⌥R。翻译来源输入框中选中的文字（没有选中时为整个输入框），完整成功后经剪贴板粘贴替换原文。与全局翻译快捷键共用会话和译文卡片。

**全局翻译快捷键**：可配置的 macOS 快捷键，读取当前允许的文字选区并直接开始翻译。它在同一个不激活的翻译浮层里，用新的选区会话显式替换仍保留的结果。读取为空时保留失败卡片，不静默隐藏浮层。

**排除集合**：持久保存的一组应用 Bundle ID。这些应用里，自动手势和全局翻译快捷键都不采集文字。

**选区会话**：一次交互，以会话 ID 标识，从一次被接受的文字选区开始。选区被替换、确认清空、被关闭，或用户离开来源应用时，自动翻译触发状态结束。显式激活后，翻译结果状态在被动选区和来源应用变化期间保持。Esc 和关闭按钮结束会话；全局翻译快捷键可以显式替换它。进行中的翻译保留激活时选定的服务和语言方向。

**选区手势**：鼠标拖选、双击、三击、全选手势，或 Shift 配合方向键、Home、End、Page 键。鼠标手势需要可读的选中文字；键盘手势可以进入待确认的翻译触发状态。Command 或 Option 可以按行或按词收窄 Shift 选区。

**全选手势**：允许的文本上下文中的 ⌘A。可读文字时创建选区会话；否则创建待确认触发，必须显式激活后才读取。

**文本选区上下文**：获得焦点、呈现文档或字段文字的控件，例如文本区域、文本框、网页区域或聊天消息列表。文件树和表格不是文本选区上下文。

不要使用：任意选中字符串、文件名选区

**选区上限**：一次翻译接受的最多 50,000 个字符。超限选区可以显示翻译触发状态，但激活后在本地以超限提示结束，不向翻译服务发送文字。

不要使用：无限选区、静默拒绝

**应用排除**：用户持久选择，禁止在某一个 macOS 应用中开始选区会话。只要选中文字可读，应用默认允许采集。

不要使用：全局暂停、可编辑字段排除

**翻译浮层**：不激活、可拖动的界面。整个触发按钮和结果卡片顶部 56pt 标题区可以拖动；关闭按钮和可选中的正文是各自独立的操作区域。文字采集完成后，浮层首先出现在最新鼠标位置旁，并夹在可见屏幕内。当前会话保持该位置；内容尺寸不变时不重新摆放窗口。一次新的显式翻译替换会重新锚定位置。

不要使用：浮动窗口、弹出窗口

**翻译触发状态**：翻译浮层的折叠状态，显示为一个 84×30pt 的圆角「翻译」按钮。点击开始翻译；拖动移动浮层，并保持来源应用的键盘焦点。

不要使用：翻译按钮（作为状态名）

**翻译结果状态**：保持显示的展开翻译浮层，展示进度、译文、错误或选区上限。切换来源应用、点击外部、清空选区、新的被动选区和设置变化都不关闭它。Esc 或关闭按钮关闭它。全局翻译快捷键可以用一次新翻译显式替换它。

不要使用：结果窗口

**翻译历史**：成功完成的翻译结果按时间保留下来的集合，可以在原来的选区会话之外浏览。取消、失败和未完成的尝试不在其中。

不要使用：历史页、翻译缓存

**翻译历史窗口**：从菜单栏打开、用来浏览翻译历史的独立应用窗口。它与翻译浮层分开。

不要使用：浮层历史、历史面板

**记录历史**：用户是否把以后的翻译记录写入翻译历史。默认开启；关闭后保留已有翻译记录，并阻止新记录。

不要使用：隐私模式、清空历史

**翻译记录**：翻译历史中的一条。包含原文、译文、检测语言、实际目标语言、翻译服务、可选模型名、完成时间，以及来源显示名（应用名或「截图」）。每次完整成功的选区翻译或截图文字翻译都新增一条，重复原文也新增。取消、失败、未完成或过期的截图结果不写入。记录不保存选区坐标、截图图片或凭据。没有来源信息的记录显示明确的未知来源。

不要使用：请求日志、活动记录

**翻译增量**：翻译结果状态中追加的一段译文。每个翻译服务在完成前都产生一次或多次翻译增量，包括一次返回全部结果的服务。

不要使用：服务响应、流式分块

**分段翻译**：对长选区的一次翻译。按原文顺序逐段处理翻译分片，并显示为一段连续结果。

不要使用：批量翻译、多次翻译

**翻译分片**：分段翻译中按顺序发给翻译服务的一段，一次请求一段。一段以约 4,000 字为目标，为保住段落可以延到 6,000 字；只有超过 6,000 字的段落才继续按句子拆分，最后才按字符硬切。

不要使用：流式分块、拆开的段落

**滑动翻译上下文**：紧邻的上一个翻译分片的有限尾部，提供给下一次模型翻译请求以保持语义连续。最多包含前一段原文 1,000 字和前一段译文 1,000 字，不累积更早的分片。Google 类翻译服务不使用它。

不要使用：完整翻译历史、累积提示词

**分片失败**：发生在一个翻译分片上的翻译失败。已完成的分片保持可见，重试从失败的分片继续，全部分片成功后才创建翻译记录。

不要使用：重新开始的翻译、部分翻译记录

**主要语言**：选中文字不是主要语言时的目标语言。初始值跟随用户的第一个 macOS 偏好语言。

不要使用：固定目标语言

**次要语言**：可选目标语言，用于检测结果为主要语言的文字。默认不设置，可以清空并保存。设置后必须与主要语言不同。

不要使用：回退语言

**检测语言**：翻译开始前在设备上确定的源语言。同一次选区会话中，每个翻译服务收到的检测语言相同。

不要使用：服务端检测语言

**翻译方向**：设置了次要语言时，检测为主要语言的文字以次要语言为目标，其余或无法识别的文字以主要语言为目标。未设置次要语言时，所有选区都以主要语言为目标。已经是目标语言的文字直接返回并保留段落配对，不发起外部翻译请求。

不要使用：手动源语言

**翻译服务**：选区会话中负责翻译文字的外部来源。官方翻译产品、非官方翻译端点和语言模型使用同一套翻译请求和结果语义。

不要使用：翻译内核、模型引擎

**模型配置**：一个可复用的命名配置，对应一个模型翻译服务及其翻译提示词。可以同时存在多个模型配置，其中任意一个都可以选为默认翻译服务。

不要使用：模型连接、服务实例

**翻译提示词**：属于一个模型配置、可由用户编辑的指令，告诉该模型翻译服务如何生成译文。其中没有请求变量，因为选中文字和翻译方向单独提供。每个模型配置以同一份默认指令开始。Google 类翻译服务不使用翻译提示词。

不要使用：Google 提示词、隐藏系统提示词

**默认翻译提示词**：初始翻译提示词。要求只输出译文，保留段落和换行，保持类似代码的内容不变，遵循给定的翻译方向，并使用滑动翻译上下文且不重复它。

不要使用：解释性翻译、复述上下文

**默认翻译服务**：用户激活翻译触发状态后立即使用的翻译服务。它在当前选区会话之外选定，翻译开始前不需要再选一次。初始使用 Google 免费接口，以便零配置翻译。

不要使用：按次选择的服务

**翻译失败**：默认翻译服务未能完成一次翻译。选中文字不会自动改发给另一个翻译服务。

不要使用：服务故障转移

**官方谷歌服务**：使用 Google Cloud Translation、由用户的云凭据配置的翻译服务。

**Google 免费接口**：使用 Google 翻译消费端接口的翻译服务，可用性没有保证。

**OpenAI 兼容服务**：按 OpenAI 兼容端点和模型配置的模型翻译服务。主机为官方 `api.deepseek.com` 的配置通过协议关闭思考。

不要使用：OpenAI 服务（作为全部兼容端点的统称）

**Anthropic 服务**：按 Anthropic 原生模型端点配置的模型翻译服务。

**Apple 系统翻译**：使用 macOS 本机翻译模型的翻译服务，无端点、无凭据，只能翻译已下载语言包的语言对。

不要使用：OpenAI 兼容的 Claude
