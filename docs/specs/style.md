## 适用范围与决策边界

1. 本文适用于设置、翻译浮窗、截图工具栏、翻译历史窗口、权限向导及其控件、菜单和弹窗的设计、实现、重构与审查。
2. 本文约束 UI 实施方式，不表示某个组件库已经安装、界面已经完成改造或最低系统版本已经调整。功能与平台范围以用户明确确认、来源工单和对应会话上下文为准。
3. Flutter/Dart 负责界面和业务，Swift 负责 macOS 系统能力。玻璃材质的接入不得擅自改变这条职责边界，也不得把视觉改造扩大成业务重写。
4. 通用设计规则适用于 Apple 原生 Liquid Glass 与 Flutter shader 实现。本文的 `Glass*` API 条目专属于 `liquid_glass_widgets`，不得套用到 `real_liquid_glass`、AppKit 或 SwiftUI。
5. 平台下限、依赖引入、跨版本兼容和运行时降级方案需要用户授权。采用 macOS 26+ 原生材料时，不额外建设未授权的旧系统兼容分支。系统要求的可访问性支持必须保留。
6. 外部示例用于核对组件职责和 API，不直接决定本项目的桌面导航、窗口行为或布局。实施前核对所选版本的公开文档与源码。

## 材质、内容与层级

1. 玻璃主要承载导航和交互：工具栏、导航栏、独立浮动按钮、菜单、弹窗以及需要与背景分离的浮动面板。
2. 全应用统一视觉语言，不等于把所有内容都做成折射层。原文、译文、截图、长列表内容及图片展示保持清晰，内容区域采用适合阅读的背景与标准材料。
3. 玻璃后方使用真实界面内容或系统允许的背景材料。不要仅为显现玻璃效果而添加与翻译、截图无关的装饰壁纸或动画背景。
4. 不在一个折射玻璃容器内嵌套另一个折射玻璃控件。多个层的重复折射会影响文字清晰度、裁切交互动效并增加合成开销。
5. 一个玻璃面板内部使用普通文字、图标和不自行折射的控件；需要独立玻璃表面的按钮、分段选择器、开关或滑块放在面板之外，或采用组件库明确支持的共享材料方式。
6. 列表分组可共享一个材料层，组内条目不重复创建玻璃背景。密集历史列表不得每行叠加高开销折射效果。
7. 导航与工具层位于内容层上方；滚动内容不能覆盖操作按钮。边缘渐隐、内边距和安全区域应与实际工具栏尺寸一致，不能遮住正文或拦截正文操作。
8. 原生系统材料与 Flutter shader 材料是不同实现。使用 Flutter 仿制效果时，不将其描述为 Apple 原生控件或系统材料。

## 主题、可读性与可访问性

1. 由统一主题管理明暗模式、模糊、透明度、边缘高光、强调色、圆角和交互动画；各窗口沿用相同语义，不散写互不相关的样式值。
2. 图标和文本在浅色、深色、复杂图像及滚动背景上都必须保持足够对比度。玻璃表面变化时，前景颜色与焦点状态也要保持可辨识。
3. 强调色用于主要操作和必要状态，不同时给所有玻璃按钮染色。控件的前景色由其材料规则统一决定，避免与自动明暗切换冲突。
4. 保留系统的减少动态效果、减少透明度和增强对比度偏好；不可为了视觉效果关闭可访问性支持。
5. 保留键盘操作、可访问名称、焦点指示、悬停提示及合理点击区域。图标按钮必须能通过提示和语义名称识别功能。
6. 视觉改造不改变业务完成条件、失败提示、输入校验或数据保留行为。加载、禁用、错误和成功状态都必须清楚可见。

## 截图与多窗口约束

1. 截图工具栏始终完整位于当前屏幕内，优先靠选区边缘的外侧空白放置；外侧不足时，允许进入选区内部靠边。根据可用空间选择上、下、左、右。
2. 不能为了放置工具栏缩小或移动截图画布。玻璃工具栏、阴影、控制点和状态提示均属于 UI，不进入复制、保存或贴图使用的图片。
3. 布局与材质更新不得改变源图像素坐标、裁剪范围、标注历史或导出分辨率；指针、显示和源图的坐标变换必须一致。
4. 保持普通设置窗口、历史窗口、截图编辑层、独立贴图及非激活翻译浮层的职责。玻璃化不能使普通窗口意外置顶，或使翻译浮层抢占来源应用焦点。
5. 各 Flutter 引擎分别拥有初始化与主题入口，不能假设主引擎的材质状态自动共享给其他窗口。仅为实际使用该材质的入口接入所需能力。
6. 键盘确认动作依据当前编辑状态分派：文字输入时回车确认文字、Shift+回车换行；截图确认时回车或小键盘回车复制截图并退出。复制失败保留编辑内容。不能让新控件吞掉这些事件或重复提交。
7. 截图回车可靠性必须覆盖真实窗口焦点和原生键盘传递路径；材质或布局调整、纯 Widget 测试均不能单独作为可靠性证据。

## 性能与生命周期

1. 根据实际设备验证启动、滚动、拖动、窗口切换及连续截图的帧耗时、内存和响应；不依据演示视频或组件文档直接承诺固定帧率。
2. 控制材料层、形状混合和动态效果的数量；优先复用已有分组与主题能力，不为每个条目独立创建昂贵的折射层。
3. 初始化和必要的 shader 准备应遵循所选库的公开接口，避免在控件重建时重复执行。首次打开窗口不得因同步重计算出现明显白帧或长时间停顿。
4. 复杂动画只用于需要表达状态变化的位置。动态显隐不能改变按钮的稳定点击区域或让正在输入的控件失去焦点。
5. 设备性能自适应、质量档位与系统可访问性是不同概念；需要额外质量降级策略时，先遵守用户对兼容和降级的授权边界。

4. 验证减少动态效果、减少透明度及增强对比度下的可读性与操作能力。
5. 使用项目现有 Flutter 测试和静态检查验证实际输入输出及状态变化；原生材料或窗口桥接变更运行相应原生检查。不能只断言某个下游方法被调用。

## 当前原生实现的颜色与材料契约

1. `NativeGlassApp` 是设置、翻译浮层、截图、历史、权限窗口的主题入口；`NativeGlassTheme.data` 是控件语义配色的唯一定义。`NativeGlassSurface(material: true)` 给交互控件创建 `NSGlassEffectView`，默认 `material: false` 为阅读背景。
2. 普通按钮、图标按钮、输入框、下拉触发器与弹出菜单项使用独立材料；开关和滑块不绘制外壳材料；外观与导航分段使用平整轨道，不增加折射高光。父控件内部的已选项共享父材料，不重复折射；菜单进入独立路由后获得自己的材料。对话框背景和历史正文使用阅读背景，内部操作使用控件材料。
3. 普通窗口使用 `NativeGlassWindowContent.windowCanvas` 与 `NativeGlassWindowPage` 的统一阅读底色，覆盖标题与正文：浅色 #F7F7F7、深色 #171717，不透明度100%。窗口外圆角由AppKit管理，Flutter根页面圆角0，不在红绿灯下方生成第二个面板。交互内容避开系统 `contentLayoutGuide`，红绿灯、标题和窗口拖动保留。

| 语义角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| surface | #F7F7F7 | #171717 | 阅读背景，面板以78%不透明度绘制 |
| onSurface | #000000 | #FFFFFF | 主文字、普通按钮、图标、开关滑块前景 |
| onSurfaceVariant | #454545 | #CCCCCC | 次级文字、说明、辅助图标 |
| outline | #696969 | #929292 | 需要明确区分的边界 |
| outlineVariant | #C5C5C5 | #505050 | 输入框默认边界、分隔与控件轨道 |
| primary | #005BC5 | #64ACFF | 主要动作、聚焦边框和选中状态 |
| onPrimary | #FFFFFF | #000000 | 主强调色上的前景 |
| content | #F2FFFFFF | #F2232323 | 卡片、菜单与弹窗阅读底色 |
| error / onError | Material ColorScheme.fromSeed(#0A84FF, light) | Material ColorScheme.fromSeed(#0A84FF, dark) | 错误文案、错误边框与错误操作；不靠颜色单独传达错误 |
| native tint | 白色16% | 黑色16% | NSGlassEffectView 的染色；不修改文字透明度 |

1. 默认状态使用 `onSurface`；普通按钮悬停与按下分别使用6%和12%的 `onSurface` 状态层，过渡120ms，减少动态效果时0ms；键盘焦点使用2点 `primary` 边框。输入聚焦使用2点 `primary` 边框，错误使用 `error`；选中分段使用 #007AFF 背景和 #FFFFFF 文字，两种主题均不改为黑字；选中开关轨道使用 `primary`，未选轨道使用 `outlineVariant`，滑块为白色。禁用状态采用主题的标准禁用前景及语义禁用，不通过移除提示或缩小点击区域表达禁用。
2. 截图复制成功反馈使用普通高对比度前景和明确“已复制”文案，显示1秒；失败保留可读文本。不得把成功/失败仅表示为短暂颜色变化。
3. 通用设置中的透明度范围0%–80%，默认20%；存储 `glassOpacity` 为材料不透明度0.2–1，`glassAppearance` 为 `system/light/dark`。更改后自动保存，通过独立外观通道向已打开引擎广播，下一次启动从已保存偏好读取。外观广播不替换业务草稿。
4. 系统“减少透明度”或“增强对比度”优先，原生材料不透明度为1；增强对比度外观由 AppKit 材料承担。手动浅/深色固定主题，跟随系统由 Flutter 平台亮度通知更新。
5. 材料透明度只作用于原生材料视图，前景文字图标保持不透明。截图画布、导出PNG、原文译文以及历史数据不参与材料转换。

```dart
// 普通页面保留阅读背景，独立操作拥有自己的原生材料。
NativeGlassSurface(
  child: NativeGlassSurface(
    material: true,
    radius: 8,
    child: TextButton(onPressed: save, child: const Text('保存')),
  ),
)
```

新增界面必须复用上述主题与材料入口和下方数值规格，不在业务页面散写另一套颜色值。增加状态或材料角色时同步本表，并验证浅/深色、系统外观变化、透明度端点、未保存输入、键盘焦点与原图导出。

## UI 数值规格（TranslateApp）

本节是设置、翻译浮层、截图工具栏、历史、权限及弹窗的尺寸依据。单位为逻辑 pt；Retina 按屏幕倍率渲染。下表控件尺寸指可见轮廓，点击区域另按最低32×32设置；菜单项的28pt可见行上下各留2pt点击空间。原生窗口标题、红绿灯由AppKit管理，Flutter内容不得覆盖系统contentLayoutGuide。标题与正文共享100%不透明阅读底色（浅#F7F7F7、深#171717），Flutter根页面圆角0，窗口唯一外轮廓由AppKit裁剪。

页面四边22；组间20；单行设置项最小高40，带一行说明最小高60；左右文字/控件间距至少16；标题与输入间距6，输入与帮助文字间距6。页面标题20/26粗体；分组标题14/20半粗体；正文、按钮、输入13/18；说明12/17（字号/行高）。分隔线1；边框1；键盘焦点框2。普通按钮悬停层6%，按下层12%；分段切换项悬停0%、按下浅色8%/深色10%；状态过渡120ms，减少动态效果时0ms；独立控件点击区域至少32×32。

自适应规则：卡片高度＝各行实际高度之和＋分隔线＋上下32内边距；每增加一行正文增加18。空间不足时控件移到下一行，间距8；不得缩小字号或裁切标签/当前值。长下拉值在120–240宽度内换行，高度按18行高增加；长菜单项同理。多行输入超过160高度在内部滚动。截图复制提示超出视口时换行，保持每行18和上下10内边距；不改变截图原图。截图工具栏厚度48＝上下/左右8+图标按钮32，屏幕边距及选区间距8；按钮沿主轴滚动，画布不缩放。

交互：外观使用平整三段选择：未选轨道为10% onSurface、无折射高光，选中背景#007AFF、文字#FFFFFF；语言/服务使用紧凑菜单，开关统一采用主题强调色；字段标题在轮廓之外。页面/分组为稳定阅读背景，菜单共享一个材料层，短按钮材料贴合轮廓。离散设置立即自动保存，滑块结束调整时提交；服务弹窗确定后整体提交，取消不写入配置或凭据。失败保留草稿、显示错误并允许重试；旧事务/加载快照不能覆盖新编辑。

验收：量测可见轮廓、圆角、字号、间距和点击区域；覆盖浅/深色、长中文/长服务名、窄窗口、键盘焦点、减少动态效果、透明度0%和80%、快速连续编辑、保存失败/冲突与重启保持。规格是后续数值调整的来源，本地规则与代码常量同步更新。

## 设置页面与服务约束

### 光标选择工具

四角须显示系统原生对角双向拉伸光标：左上/右下为↖↘，右上/左下为↗↙。截图区域与文本框采用同一规则，覆盖悬停、按下拖动、离开与关闭编辑器；系统管理光标外形与缩放，应用不自绘替代图标。验收必须核对原生实际光标，不能仅以Flutter枚举名称作为通过依据。

光标工具可选中、拖动、拉伸已有文本框与截图区域；命中优先级为当前文本框控制点、最上层文本框、截图控制点/边框、截图内部。文本框选中后显示边框及控制点，双击编辑文字。截图未选中预览单击后进入可移动/拉伸状态；光标工具不新建截图区域，新建框选由裁剪工具承担。截图边框1pt、八点直径8pt/命中24×24pt、边框命中内外各6pt，沿用相应方向的拉伸光标；文本框沿用同一控制点及命中尺寸。单次拖动只改变命中的对象。

### 贴图与输入事件

贴图显示不激活来源应用，首次按下立即接收拖动；图片上不显示关闭按钮或覆盖工具，右上角遮挡面积0pt。按下选择该贴图后Escape只关闭它，双击同样只关闭当前图。截图编辑的普通字符及合法长按原样交给输入系统；文字编辑时Command+Z等编辑命令与输入法回车不应被原生截图确认提前消费。不得采用字符去重或时间防抖掩盖重复输入。

## 样式验收边界

1. 分段控件的无hover要求覆盖实际按钮叠加层与外部反馈层；测试比较鼠标进入前后控件的渲染结果，不仅检查主题配置。选中状态、按下反馈和键盘焦点分别保留。
2. 第二行模式按钮的玻璃材料独立贴合32×32pt轮廓；材料覆盖不进入画布导出，整条工具栏仍透明。
3. 历史标题、正文、来源、日期分别在浅色与深色主题下核验；切换主题无需关闭窗口，新增记录无需手工刷新。布局与颜色测试不能替代用户对原生玻璃效果的验收。


### 录制目标预览

选择全屏时，选区边框覆盖冻结帧来源显示器；选择窗口时，所有显示器呈现固定联合画布的边界，选中应用后突出其可见窗口，其余区域遮暗。预览不修改图片裁剪，返回区域目标时恢复原选区。取消准备或开始采集时释放预览遮罩。边框沿用1pt强调色，遮暗沿用60%黑色；窗口位置按来源列表的快照显示，实际采集在开始时重新校验。
