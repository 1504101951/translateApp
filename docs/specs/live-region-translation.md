## 已确认结论

1. **入口与捕获目标**
   1.1 实时翻译是截图中的工具，不提供专用快捷键。
   1.2 复用录制准备流程，选择区域、窗口或全屏后点击开始；准备阶段不启动持续 OCR 或翻译。
   1.3 “窗口”沿用录制的应用 Bundle ID 契约，捕获该应用的窗口集合；全屏沿用截图来源显示器。
   1.4 窗口、全屏、捕获及范围标记复用现有能力和样式。画面帧直接送设备 OCR，不生成录屏文件。

2. **原位覆盖译文**
   2.1 在来源画面的原文字位置覆盖显示对应译文，不另设独立结果窗或原文对照区。
   2.2 盖层不抢来源应用焦点、不阻挡来源应用操作，并从捕获中排除。
   2.3 原文和对应位置必须来自有效识别结果；滚动、移动或布局变化后不能在错误位置显示旧译文。
   2.4 翻译单元是段落块：一次识别得到的一个段落，含段落原文和屏幕上的外接矩形。盖层为白底 80% 不透明（`0xCCFFFFFF`）、黑色半粗体，按段落块绘制，盖住该段原文的外接矩形，译文在矩形内换行。
   2.5 译文超出段落块矩形时缩小字号，使整段留在矩形内，不遮挡相邻文字。长译文可以小到难读。不把译文挪到矩形外。
   2.6 顶部菜单栏中止仍执行结束语义；运行中不占用来源应用 Escape，结束或放弃后恢复普通图标。

3. **活动控制与会话边界**
   3.1 暂停／恢复、结束、放弃使用录制和滚动长截图的同一活动控制条，沿用业务语义，不另造控制组件。
   3.2 暂停停止本次捕获、OCR 与网络工作并保留本次会话，同时撤掉译文盖层，恢复来源原画面。恢复后沿用同一捕获目标，重新识别当前画面；命中段落块缓存的段落块不重复发送，盖层放到新位置。
   3.3 结束停止后台工作，不等待后续翻译完成，立即清除译文盖层，恢复来源原画面；菜单栏中止同样执行该行为。
   3.4 放弃取消工作、清理本次内容并移除盖层。
   3.5 每次启动独立会话，无活动会话内更换目标入口。不持久化或继承前次目标、原文、译文、分段进度、去重记录、失败任务及运行状态；不自动写入历史。
   3.6 本次运行只保留去重、调度与拒绝迟到事件所需的内存状态，其中包含段落块缓存；缓存暂停时保留，结束或放弃时清空。应用全局服务设置不是会话记录；资源释放期间的在途槽位不得提前复用。

4. **请求与失败处理**
   4.1 不提供手动重试入口。只有当前画面中未命中段落块缓存的段落块可进入发送，已离开画面的失败段落块不排队。
   4.2 段落块已在在途批次中或已命中缓存时，不重复发送。
   4.3 失败按错误类别处理；编号缺失或对不上的段落块单独补发一次。
      4.3.1 服务级明确错误（认证失败、额度或频率受限、服务拒绝配置）不重试：本次会话停止发送新批次并丢弃待发送段落块，直到会话结束。
      4.3.2 段落级明确错误（模型拒绝翻译、输出达到长度上限、段落超过本地长度上限）该段落块不重试，其他段落块照常。
      4.3.3 临时错误（无法连接、超时、服务端错误、响应不完整或无法解析）后，其中仍在画面上且原文未变的段落块可在满足请求开始间隔后再次发送，同一段落原文在本次会话内最多重试 3 次；重试次数在会话结束时清零。
   4.4 本地输入校验不通过时不发送网络请求；不自动切换 Provider。
   4.5 单纯修改服务、目标语言或模型不打断在途批次；画面上未变化的段落块保持已有译文，新出现的段落块按新设置翻译。每个批次保持一致的配置快照；独立新会话使用开始时的当前设置。
   4.6 未命中的段落块合并为批次发送，模型服务用编号对应批次内的原文与译文；语言识别按批次执行一次。
   4.7 段落块缓存的键为“段落原文＋目标语言＋服务”，逐字相同才算命中，不做相似匹配或前缀匹配；已离开画面的在途结果仍写入缓存。

5. **性能配置**
   5.1 采集间隔 200ms、段落块发送等待 200ms（按单个段落块计时）、请求开始间隔 500ms 为已批准初始值。
   5.2 三个值集中为命名配置项，注明毫秒单位与作用，便于后续修改；配置实现与规格的一致性在实施核验中检查。
   5.3 初次开始的首个非空画面不额外等待；恢复保持本次请求间隔，未命中的段落块按发送等待规则处理，同文失败按失败重发规则处理。
   5.4 最多一个 OCR 执行中与一个最新待处理帧；最多 3 个在途批次（非官方谷歌接口为 1 个），单批最多 20 个段落块或 2000 字符，先到为准；成功结果与错误均须核对当前会话和段落块原文。
   5.5 在途批次不因画面文字变化而取消；最新画面不再包含该批次的任何段落块时取消。暂停、结束、放弃与采集失效取消全部在途批次。
   5.6 段落块缓存内存预算 100 MB，按“原文与译文字符数 × 2 字节”估算占用，超出时淘汰最久未用的条目。
   5.7 画面变化面积过小时不触发 OCR；面积阈值待实测后确定，确定前不实施该项。

## 技术核验事项

1. **译文如何对应原文？** 设备 OCR 的段落识别给出段落块，批次内编号关联译文与段落块；流式增量按编号归属，不能把未确定归属的片段画到任意段落块。
2. **页面变化时如何防止错位？** 内容与位置分别判断有效性；同文移位不必重复翻译，但盖层位置必须重新核验。覆盖滚动、窗口移动、应用窗口集合变化、显示器与像素倍率转换；段落原文相同不足以决定盖层位置有效。
3. **空间不足时能否满足已确认规则？** 密集页面不假设必有可用空位。译文超出段落块矩形时缩小字号以保留整段，不遮挡相邻文字，不省略句尾，不把译文挪到矩形外。
4. **盖层如何复用现有能力？** 核验截图绘制与系统原位盖层的边界；盖层须点击穿透、不抢焦点、排除自身捕获。暂停、结束、放弃及捕获失效时清理盖层。继续后的位置以新的有效识别结果为准。
5. 上述技术事项由实现方结合现有 OCR、翻译契约与绘制能力提出最小方案，不要求用户选择内部数据结构，也不直接照搬截图中的上下挪动避让算法。
