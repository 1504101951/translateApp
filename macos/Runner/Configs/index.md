# macos/Runner/Configs目录索引

应用标识、编译模式与警告配置。

1. [AppInfo.xcconfig](AppInfo.xcconfig)：配置应用名称、Bundle标识与版权信息。
2. [Debug.xcconfig](Debug.xcconfig)：组合调试模式所需的Flutter与编译配置。
3. [Release.xcconfig](Release.xcconfig)：组合发布模式所需的Flutter与编译配置。
4. [Warnings.xcconfig](Warnings.xcconfig)：集中启用原生代码的编译警告规则。
5. [index.md](index.md)：索引本目录直接子文件和子目录的用途。
