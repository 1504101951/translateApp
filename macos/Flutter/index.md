# macos/Flutter目录索引

Flutter引擎构建配置与插件注册入口。

1. [Flutter-Debug.xcconfig](Flutter-Debug.xcconfig)：引入Flutter调试构建所需的生成配置。
2. [Flutter-Release.xcconfig](Flutter-Release.xcconfig)：引入Flutter发布构建所需的生成配置。
3. [GeneratedPluginRegistrant.swift](GeneratedPluginRegistrant.swift)：注册Flutter工具根据依赖生成的macOS插件。
4. [index.md](index.md)：索引本目录直接子文件和子目录的用途。
